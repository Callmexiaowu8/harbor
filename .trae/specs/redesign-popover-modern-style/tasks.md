# Implementation Notes

## 开发策略
1. **渐进式修改**：每个 Task 内部按 Subtask 逐步修改，每完成一个 Subtask 就编译验证
2. **并行开发**：Task 1-4 可以分配给不同的 sub-agent 并行处理
3. **版本控制**：建议在每个 Task 完成后创建 git commit，便于回滚

## 关键文件修改清单
- `Sources/harbor/Views/MainView.swift` - Task 1
- `Sources/harbor/Views/ServiceListRowView.swift` - Task 2, 3, 4
- `Sources/harbor/Views/Theme.swift` - 可能需要微调（如果新样式需要新的 color token）
- `Sources/harbor/Views/EmptyStateView.swift` - Task 5（如需适配）

## 风险点
1. **Dark Mode 适配**：新透明度值可能在 dark mode 下不够明显，需要实际测试
2. **性能影响**：更大的按钮和内边距可能略微影响渲染性能（通常可忽略）
3. **向后兼容**：确保不改变任何 callback 签名和数据模型
